# 빈자리 카드

**가로와 세로에 1부터 6까지 한 번씩.** 화면을 보지 않고도 VoiceOver로 위치와 카드 정보를 확인하며 풀 수 있도록 구성한 1인 숫자 카드 퍼즐입니다. 스도쿠의 작은 사각형 구역 규칙은 없습니다.

아이폰 Safari, 안드로이드 및 PC의 최신 브라우저에서 사용하는 정적 웹 게임입니다. 회원가입, API 키, 데이터베이스, npm 설치, 빌드가 필요하지 않습니다. 외부 글꼴·광고·분석 도구·네트워크 API를 사용하지 않습니다.

## 바로 실행

압축을 풀고 `index.html`을 브라우저로 열면 플레이할 수 있습니다. 로컬 파일의 저장 지원은 브라우저마다 다르므로, 실제 배포는 GitHub Pages의 HTTPS 주소를 권장합니다.

## GitHub Pages에 올리기

1. GitHub에 공개 저장소(예: `blank-card`)를 만듭니다.
2. **이 폴더 안의 파일과 tests 폴더**를 저장소 최상위에 올립니다. ZIP 파일 자체를 올리는 것이 아닙니다.
3. 저장소 **Settings → Pages → Build and deployment → Source → Deploy from a branch**를 선택합니다.
4. Branch를 **main**, 폴더를 **/(root)**로 선택하고 Save를 누릅니다.
5. 배포가 완료되면 Pages 설정에 표시되는 주소를 아이폰 Safari로 엽니다.

`index.html`이 저장소 최상위에 있어야 합니다. `Blank-Card-Web/index.html`처럼 한 단계 안에 올리지 마세요. 자세한 과정은 [INSTALL.md](INSTALL.md)에 있습니다.

## 구현한 구성

- 6×6, 숫자 1~6. 무작위 문제를 만들고 정답 유일성 및 논리 풀이 가능성을 검사합니다.
- 한 칸의 유일 후보, 한 가로·세로에서 특정 숫자의 유일 위치만으로 끝까지 풀리는 문제를 제공합니다.
- 카드판에서 자리 선택, 가로·세로 읽기, 현재 자리의 입력 지우기.
- 카드판 아래에 **숫자 입력 · 지우기** 배치. 게임 내 ‘방법’ 버튼 없이 플레이 설명은 PLAY.md에 제공.
- 빈칸을 실행하거나 ‘숫자 입력’을 실행하면 해당 카드 근처에 숫자 선택창이 열립니다. 첫 숫자로 초점을 옮기고, 성공 또는 취소 후에는 ‘숫자 입력’ 버튼으로 복귀합니다. 선택창 안에서도 가로·세로 정보를 확인할 수 있습니다.
- 고정 카드와 입력 카드 구분. 중복 입력은 위치를 설명하며 거부합니다.
- 개별 카드와 가로·세로 낭독에서 ‘고정·입력·빈칸’을 일관되게 안내합니다. 줄 낭독에는 각 칸의 행 또는 열 번호도 포함합니다.
- 자동 저장과 새로고침 후 이어하기. 이 기기·브라우저 안에만 저장합니다.
- VoiceOver 표준 조작, 동적 상태 안내, 키보드 조작. 독립 음성은 VoiceOver와 중첩되지 않도록 재생하지 않습니다.
- 일반 글자 크기 및 약 632px 이상의 사용 가능한 세로 공간에서 스크롤 없는 게임 화면을 목표로 합니다. 작은 화면에서는 스크롤을 허용하여 버튼이 잘리지 않게 합니다. 게임 방법은 PLAY.md에 제공합니다.

**10~30분은 설계 목표입니다. 실제 시각장애인 플레이 시간과 실제 iPhone Safari·VoiceOver 사용성은 아직 실측하지 않았습니다.** 문제에 따라 더 빨리 풀릴 수 있으며, 접근성 인증 또는 실기기 검증 완료를 주장하지 않습니다.

## 파일 구성

| 파일 | 역할 |
| --- | --- |
| `index.html` | 게임 화면, 숫자 선택창, 새 판 확인 창 |
| `style.css` | 반응형 배치, 명암 테마, 포커스 표시 |
| `engine.js` | 규칙, 정답 수 검사, 논리 풀이, 문제 생성 |
| `app.js` | 조작, 낭독 문구, 자동 저장 |
| `icon.svg` | 브라우저 아이콘 |
| `.nojekyll` | GitHub Pages 정적 파일 배포 보조 |
| `tests/engine.test.cjs` | 문제 생성 및 규칙 회귀 검사 |

## 개발 검증

Node.js가 설치되어 있다면 프로젝트 폴더에서 다음을 실행합니다. 일반 플레이에는 Node.js가 필요 없습니다.

```sh
node --test tests/engine.test.cjs
```

로컬 HTTP 서버가 필요하고 Python이 설치되어 있다면:

```sh
python -m http.server 8080 --bind 127.0.0.1
```

PC 브라우저에서 `http://127.0.0.1:8080`을 엽니다. 이 주소는 같은 PC용이며 아이폰에서 접속할 주소가 아닙니다. 아이폰에서는 GitHub Pages 주소를 이용하세요.

## 저장·개인정보

현재 판, 입력, 선택 위치를 `localStorage`에 저장합니다. 서버로 보내지 않으며 기기 간 동기화하지 않습니다. 저장 공간이 막힌 환경에서는 경고 후 현재 창 안에서 플레이할 수 있습니다. 사이트 데이터를 지우면 저장도 사라집니다. 여러 탭에서 동시에 같은 저장을 편집하는 사용은 지원하지 않습니다.

이전 버전의 저장이 있으면 현재 판과 입력 숫자는 이어갑니다. 제거된 메모 및 되돌리기 기록은 사용하지 않으며, 다음 저장부터 새 형식으로 저장합니다.
